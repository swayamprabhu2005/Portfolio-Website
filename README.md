# Swayam Kiran Prabhu — Personal Portfolio

> **Computer Engineering • Software • AI • Systems**  
> *"Building software systems today, exploring intelligent systems for tomorrow."*

An exceptionally creative, premium, interactive digital experience engineered with **React, Vite, Tailwind CSS, Framer Motion, Three.js, and React Three Fiber**.

---

## 🌟 Key Highlights

- **🧠 Interactive 3D Neural Brain (Three.js & R3F)**: Procedurally constructed symmetrical neural network mirroring Swayam's visual artwork with pink/violet (Software & AI) and cyan/blue (Hardware & Sensors) dual hemispheres, glowing singularity core, action potential signal pulses, cursor parallax, and shockwave pulses.
- **🔬 VeritaScan Forensic AI Simulator**: Interactive deepfake inspection engine with ResNet18 spatial convolution, Fourier FFT frequency decomposition, and cryptographic authenticity scoring.
- **🚗 Automotive Black Box (BITS Pilani Goa)**: Real-time CAN Bus 2.0B hexadecimal packet stream visualizer, 6-axis IMU acceleration tracking, and edge ML crash prediction simulation.
- **💧 Smart Water Telemetry (IDEAS 4.0 Finalist)**: Multi-probe hardware monitoring (pH, Optical Turbidity, TDS) with safe/unsafe status thresholds and predictive ML contamination alerts.
- **🕸️ Interconnected Technology Ecosystem**: Interactive skill graph dynamically lighting up connected project nodes upon hover.
- **💼 Modular Professional Journey**: Spotlight on **Creative Capsule** (2-month software engineering internship) with live status pulse and verified virtual industry experiences (Deloitte, Google Cloud, Tata).
- **📜 Verified Certifications Wall**: 16 verified credentials from Anthropic (Claude), IBM (Agentic AI), NPTEL (IIT Bombay & Bangalore), Infosys, and HP LIFE.
- **⌨️ Command Palette (`Cmd+K` / `Ctrl+K`)**: Fast keyboard navigation, quick actions, PDF resume downloader, and synthesized Web Audio sound FX engine.

## 🚀 Quick Start

### Option 1: Direct Double-Click (Windows)
Double-click `run.bat` in the project root to automatically install dependencies, open the browser, and launch the development server.

### Option 2: Command Line
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 🛠️ Modifying Content

- **Internships**: Edit `src/data/internships.ts` to add or update company names, durations, and certificate links.
- **Projects**: Edit `src/data/projects.ts` to update descriptions, metrics, and repository links.
- **Certifications**: Edit `src/data/certifications.ts` to append new certifications.
- **Skills**: Edit `src/data/skills.ts` to add new skills or map them to projects.
